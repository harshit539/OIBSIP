# ATM Interface

## OASIS INFOBYTE Java Development Internship

### Task 3 - ATM Interface

A console-based ATM simulation developed using Java and Object-Oriented Programming concepts.

## Features

- User ID and PIN authentication.
- Maximum 3 login attempts.
- Transaction History.
- Withdraw money.
- Deposit money.
- Transfer money to another account.
- Insufficient Funds validation.
- Account-specific transaction history.
- Transactions stored using ArrayList.
- Menu-driven interface using switch-case.

## Java Classes

- Main.java - Starts the ATM application.
- ATM.java - Handles login, menu and ATM operations.
- Account.java - Stores account information, PIN and balance.
- Bank.java - Manages accounts and authentication.
- Transaction.java - Represents transaction records.
