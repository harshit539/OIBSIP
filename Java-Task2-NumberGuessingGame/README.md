# Number Guessing Game

## OASIS INFOBYTE Java Development Internship

### Task 2 - Number Guessing Game

A console-based Java game where the computer generates a random number and the user tries to guess it within a limited number of attempts.

## Features

- Generates a random number.
- Easy, Medium and Hard difficulty levels.
- Takes user input using Scanner.
- Displays "Too High" and "Too Low" hints.
- Displays "Correct" when the number is guessed.
- Shows the attempt counter.
- Limits the number of attempts.
- Displays the correct number when the player loses.
- Provides a Play Again option.
- Displays a round summary.

## Difficulty Levels

| Level | Range | Attempts |
|---|---|---|
| Easy | 1-50 | 10 |
| Medium | 1-100 | 7 |
| Hard | 1-200 | 5 |

## Technologies Used

- Java
- Scanner
- Random
- Loops
- If-Else Statements
- Switch-Case

## How to Run

```bash
javac NumberGuessingGame.java
java NumberGuessingGame
```
